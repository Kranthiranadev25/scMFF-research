# scMFF Research Reproduction and Evaluation

## Overview

This repository contains reproduction, debugging, evaluation, and enhancement work for the scMFF framework:

> scMFF: A Machine Learning Framework with Multiple Feature Fusion Strategies for Cell Type Identification

The project focuses on:
- scRNA-seq cell type classification
- multi-feature fusion
- classifier benchmarking
- evaluation metrics
- visualization generation
- research reproducibility
